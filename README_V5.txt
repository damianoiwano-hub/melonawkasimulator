MELONAWKA UŻYTKOWNIK SIMULATOR V5 – CAREER ONLY

Zmiany:
- każdy event ma dokładnie 3 skutki: pozytywny, negatywny i neutralny; kolejność odpowiedzi jest losowana,
- skutki/punkty nie są widoczne przed decyzją,
- czas kariery jest liczony w TYGODNIACH,
- każda nowa kariera startuje od LVL 1 i 0 punktów XP, niezależnie od punktu startowego,
- wskaźnik levelowania pokazuje postęp do kolejnego poziomu (250 XP na poziom),
- dwa zakończenia: MODERATOR lub BAN,
- baza eventów jest zamknięta: usunięto edytor, import, eksport i dodawanie eventów,
- użytkownik może operować tylko karierą, zapisami i importem/eksportem zapisu.

Warunki końca:
MODERATOR: LVL >= 10, Zaufanie >= 80, Reputacja >= 75, Kontrowersyjność <= 35 oraz min. 26 tygodni.
BAN: Reputacja <= 3 LUB Zaufanie <= 3 LUB Kontrowersyjność >= 98.

Uruchom run.bat. Domyślny adres: http://localhost:8790/
